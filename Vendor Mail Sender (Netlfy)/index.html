Step 1: File Uploads

Start by uploading your Center List Excel/CSV. Then upload the seQRview data file to automatically match records for each vendor.

Step 2: Parameters & Urgent Notes

Select Zonal Manager, Service (Biometric/Frisking), Exam Dates, and Timings. You can also add an Urgent Note which will highlight in yellow right below "Dear Concern," inside the mail.

Step 3: Rates & Dispatch

Review vendor rates, use Quick Fill or Mapping upload if needed, preview the mail format, and dispatch official emails with attachments.
